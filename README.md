# ⚖️ Landing Page - Advocacia & Consultoria Jurídica

Uma landing page moderna, responsiva e focada em alta conversão, desenvolvida para escritórios de advocacia e consultores jurídicos que procuram estabelecer uma presença digital forte e transmitir autoridade.

---

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estrutura semântica e acessível.
- **CSS3**: Estilização moderna, layout responsivo e transições suaves.
- **Git & GitHub**: Controlo de versão e hospedagem do código.

---

## 🎯 Funcionalidades

- 📱 **Design Responsivo**: Adaptado para telemóveis, tablets e computadores.
- 💬 **Foco em Conversão**: Botões de chamada para ação (CTA) integrados com o WhatsApp/Contacto.
- ⚡ **Performance**: Carregamento rápido e estrutura otimizada.
